# Dumb down

Restate your last message so it is easy to understand. Restate that one message only, not the whole thread. Text the user wrote with the trigger is part of the request: answer it in the same plain style.

- **Half the words.** Count the original's words first. Your whole reply, diagram included, uses at most half that many. If it runs over, cut detail, never decisions.
- **Plain international English**, one person talking to another. Explain or drop every path, hash, ID, code, and term of art.
- **Same facts.** Add no new facts, numbers, names, examples, offers, or opinions, and never say something was done unless the original said so.
- **Keep every decision.** Each question or choice the user must answer stays, numbered, with its reason, so the user can reply "1 yes, 2 no". Before sending, check each one from the original is there.
- **Picture only when it helps:** a flow, a before and after, or what sits where. Draw it as a small text diagram in a code block, using only facts from the original.

Keep talking this way for the rest of the thread.
